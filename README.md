# E-Commerce Web Shop

A simple e-commerce web application developed using **PHP, MySQL, and Twig**. The application allows customers to browse products, add products to their shopping cart and wishlist, place orders, and manage their accounts. Administrators have access to an admin panel where they can manage users, administrators, products, orders, passwords, and other webshop content.

## Features

* User registration and login
* Admin login and admin panel
* Product listing and product details
* Add products to shopping cart
* Shopping cart management
* Wishlist functionality
* Add and remove products from wishlist
* Place and manage orders
* Order history
* User account management
* Change password
* Add, edit, and delete products
* Manage users
* Manage administrators
* Manage orders
* Product and user administration
* Simple and responsive user interface

## Technologies

* **PHP**
* **MySQL**
* **Twig**


## Project Description

The webshop provides a simple shopping experience where customers can browse products, save products to their wishlist, add items to their cart, and place orders. The admin panel provides full management of products, users, administrators, and orders, including the ability to add, edit, or delete data and change passwords. The project is designed as a foundation for a complete e-commerce system and can be extended with additional functionality in the future.
